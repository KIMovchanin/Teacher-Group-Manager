# Frontend — Teacher-Group-Manager

Веб-интерфейс (HTML / CSS / JavaScript) поверх Go-бэкенда. Многостраничное
приложение: главная с лентой недавних действий, страница учеников и страница
групп (создание / просмотр / удаление).

## Требования

- **Go** — для запуска бэкенда (API).
- **Node.js** — для локального dev-сервера, который отдаёт фронтенд и
  проксирует запросы к API.

## Запуск

Нужно **два процесса** — бэкенд и фронтенд-сервер. Запускай их в двух
отдельных окнах терминала.

### 1. Бэкенд (API)

Из корня репозитория:

```bash
go run ./cmd/api
```

Слушает `http://localhost:8080`. В первый раз Go скачает зависимости.

### 2. Фронтенд (dev-сервер + прокси)

Из папки `frontend`:

```bash
cd frontend
node dev-server.js
```

Слушает `http://localhost:3000`.

### 3. Открыть приложение

Перейди в браузере на **http://localhost:3000**.

## Зачем нужен dev-сервер

Браузер по умолчанию блокирует запросы со страницы на другой адрес/порт
(политика **CORS**). Фронтенд работает на `:3000`, а API — на `:8080`, это
разные origin.

`dev-server.js` решает это просто: он отдаёт статические файлы фронтенда **и**
пересылает запросы `/students`, `/groups`, `/health` на бэкенд (`:8080`). Для
браузера всё происходит на одном адресе (`:3000`), поэтому CORS не возникает и
код бэкенда менять не нужно.

```
браузер → dev-server (:3000) → бэкенд (:8080)
          ├─ отдаёт HTML / CSS / JS
          └─ проксирует /students, /groups, /health
```

## Структура

```
frontend/
├── dev-server.js        # локальный сервер: статика + прокси к API
└── public/
    ├── index.html       # главная: лента недавних действий
    ├── students.html    # ученики (форма + таблица)
    ├── groups.html      # группы (форма + таблица)
    ├── style.css        # общие стили
    ├── students.js      # логика страницы учеников
    ├── groups.js        # логика страницы групп
    ├── storage.js       # лента действий в localStorage
    └── home.js          # отрисовка ленты на главной
```

## Примечания

- Данные бэкенда хранятся **в памяти** и сбрасываются при его перезапуске
  (возвращаются стартовые ученики и группы).
- «Недавние действия» на главной хранятся в **localStorage браузера** — это
  действия, выполненные через интерфейс на этом компьютере.
